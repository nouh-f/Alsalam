# نظام جرد مطعم السلام

نظام يشتغل لحاله. العامل يدخل الكمية بس، والباقي يتحسب تلقائي: يسحب المبيعات من لويفرس، ويقرأ صورة تذكرة الكاشير، ويخصم حسب الوصفات، ويطابق مع الجرد، ويطلع تقرير آخر اليوم.

## التشغيل

يحتاج **Node.js 22.5 أو أحدث**، وما يحتاج قاعدة بيانات خارجية (SQLite مدمج).

```bash
npm install
npm start            # يشتغل على http://localhost:3000
```

- البيانات تنحفظ في مجلد `data/` (قاعدة البيانات والصور). خذ نسخة احتياطية منه.
- أول دخول: **المالك** والرقم السري `1234`. بقية الموظفين `0000`. غيّرها من «الأقسام والموظفين».
- شغّله على جهاز في المطعم أو على سيرفر، وافتحه من أي جوال على نفس الرابط (يتثبت على الشاشة كتطبيق).

## التركيب على سيرفر (أمر واحد)

على سيرفر Ubuntu أو Debian جديد. ويفضّل يكون عندك دومين يؤشر على عنوان السيرفر:

```bash
git clone https://github.com/nouh-f/Alsalam.git
sudo bash Alsalam/deploy/install.sh jard.example.com
```

بدون دومين: `sudo bash Alsalam/deploy/install.sh`، ويطلع لك الرابط `http://عنوان-السيرفر:3000`.

السكربت يسوي التالي:
- يثبّت Node.js 22.
- يركّب النظام في `/opt/alsalam/app`.
- يشغّله كخدمة ترجع لحالها لو السيرفر طفى.
- يطلع شهادة HTTPS للدومين لحاله (Caddy).
- يسوي نسخة احتياطية كل يوم الساعة 4:30 الفجر في `/opt/backup/alsalam`، ويحتفظ بآخر 30 يوم.

تقدر تعيد تشغيل السكربت أي وقت، وما يمسح البيانات.

- **التحديث:** `sudo bash /opt/alsalam/app/deploy/update.sh` (ياخذ نسخة احتياطية قبل التحديث).
- **الحالة والسجل:** `sudo systemctl status alsalam` و `sudo journalctl -u alsalam -f`.

## أول مرة

1. **الإعدادات**: حط رمز لويفرس مرة وحدة. بعدها يسحب الأصناف وكل الأقسام والمبيعات المكتملة لحاله كل ١٠ دقايق، ويحفظ كل الأيام. الأصناف التجريبية تنمسح، ويسوي وصفات مبدئية تعدلها.
2. **الإعدادات**: حط مفتاح Anthropic API عشان يقرأ صور تذكرة الكاشير. بدونه تقدر تدخل التذكرة يدوي.
3. **أصناف المخزون**: عدّل الأصناف وأسعار الشراء، وأضف أو احذف أصناف.
4. **الوصفات**: لكل صنف بيع حدد مكوناته من قائمة المخزون، بكميات عشرية (مثل لحم 0.4). تقدر تحذف سطر من الوصفة بدون ما تحذفها كلها.

## الجرد اليومي

- كل قسم له شخص لأول اليوم وشخص لآخر اليوم، نفس الشخص أو غيره. تقدر تحدد غيرهم لصنف معين، مثل الدراك على صادق أو العسل على الدعدع.
- **المشرفين** (خلوف وإبراهيم) يدخلون ويعدلون ويستلمون كل الأقسام.
- **المستلمين** لكل قسم يقفلونه، مثل العسل: الدعدع يدخل الوزن وبس، والإقفال لعمار وإبراهيم وخلوف.
- الرقم المقترح لأول اليوم = آخر أمس. إذا اختلف يطلع تنبيه.
- **السحب والتحضير**: نزول بضاعة من المستودع للمعروض، مثل ٥ كيلو سمك من الثلاجة، أو تحضير حنيذ دجاج. الصنف المحضّر يسحب مكوناته من المستودع.
- **التحويل**: مثل الصهوم اللي ما انباع يصير برم أو حنيذ.
- الصنف اللي «ما يقعد لبكرة» يتحسب الباقي منه آخر اليوم هالك.

لكل صنف النظام يحسب: أول اليوم + المسحوب − المباع حسب الوصفة = **المفروض باقي**. وبعدين يقارنه بآخر اليوم، ويعطي الفرق بالكمية وبالريال حسب كل قسم وكل موظف.

## تذكرة الكاشير

- صوّر الورقة من الكاميرا أو اختر الصور من الجهاز، وتقدر ترفع أكثر من صورة. يقرأ الاسم والعدد والسعر، ويربط الأسماء بأصناف لويفرس حتى لو الكتابة مختلفة. لما تصحح الربط مرة يتعلمه للمرات الجاية.
- أصناف التذكرة تنضاف على مبيعات لويفرس لنفس الصنف، وتنخصم من المحضّر. وآخر اليوم تضغط «تأكيد».
- التذكرة **دين** وتتحسب فلوس، مو هدر. تلقاها في صفحة «الديون» حسب الزبون مع السداد.
- **الملاحظات**: تقدر تكتب ملاحظة على أي صنف، وتقدر تختار «يسحب بس من…». أو تسوي قاعدة عامة، مثل «عسل بس» على المرسة تسحب العسل بس.

## التقرير

مبيعات لويفرس + التذكرة، والمتوقع بسعر البيع مقابل الفعلي، والكاش المفروض مقابل اللي بالدرج (نقص الكاش). وفيه تكلفة الوجبات من الوصفات على سعر الشراء، والربح، ونقص البضاعة بالريال، والهالك، والتنبيهات. منها: مين ما دخّل أول اليوم أو آخره، والقسم اللي ما استلمه المشرف، والتذكرة اللي ما تأكدت، والأصناف بدون وصفة. «إقفال اليوم» يقفل التعديل إلا للمالك.

## المستودع والمشتريات

- اللي اشترى يسجل الشراء: أصناف أو صورة أو كتابة. الشراء يدخل المستودع، أو المحضّر مباشرة إذا اخترت، ويحدّث متوسط سعر الشراء.
- **جرد المستودع**: اكتب الموجود فعلًا، ويطلع لك الفرق وقيمته.
- **جرد المشتريات**: كم اشتريت، وكم انصرف، والرصيد، لآخر ٣٠ يوم.
- **المصروفات**: مبلغ وورقة أو صورة.

## الرواتب والسحبيات

الراتب الشهري ينضاف لحاله أول كل شهر. الموظف يسحب شوي شوي، وإذا سافر «صرف الباقي» يعطيه كل اللي له.
